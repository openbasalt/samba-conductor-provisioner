# conductor-provisioner

Delegated Active Directory writes for Samba Conductor: a small service that
holds a least-privilege account on the managed OUs and executes typed
operations for conductor over a local socket.

Part of Samba Conductor v2. Family design:
[architecture.md](https://github.com/openbasalt/samba-conductor-docs/blob/main/architecture.md).
